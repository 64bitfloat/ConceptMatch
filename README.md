# CLIP Concept Matcher (画像・概念類似度判定 Webアプリケーション)

OpenAIのCLIP（Contrastive Language-Image Pretraining）モデルを用いて、ユーザーがアップロードした画像と指定した「概念テキスト（プロンプト）」の類似度を0〜100%のパーセンテージで判定し、スコアが閾値（初期値: 80%）以上なら【画像A】、未満なら【画像B】を表示するStreamlit Webアプリケーションです。

---

## 🌟 主な機能と特徴

1. **CLIPモデルによる高精度マルチモーダル判定:**
   - Hugging Faceの `openai/clip-vit-base-patch32` モデルを使用し、画像埋め込みとテキスト埋め込みのコサイン類似度を算出。
2. **直感的な0〜100%スケーリング補正:**
   - CLIPのコサイン類似度は通常0.15〜0.35に集中しやすいため、自然なパーセンテージが得られるスケーリングロジック（Min-Max線形変換 / シグモイド補正）を搭載。
3. **柔軟なパラメータ設定（サイドバーUI & コード設定）:**
   - **概念テキスト（プロンプト）**: 初期値 `"a photo of a cat"`。UIから即座に変更可能。
   - **条件分岐閾値**: 初期値 `80%`。スライダーで1〜99%に変更可能。
   - **表示画像（画像A / 画像B）**: ローカルファイルパスまたは画像URLに対応。UIから手動アップロードによる差し替えも可能。
4. **ドラッグ＆ドロップ対応の画像入力UI:**
   - JPG, PNG, WEBP形式の画像アップロードに対応。
   - 準備されたサンプル画像（猫 / 犬）をワンクリックでテストできるお試しボタンも完備。
5. **わかりやすい結果表示:**
   - 判定された類似度パーセンテージを大きくグラフィカルに表示。
   - 閾値達成（>= 80%）時は「80%以上達成」メッセージと【画像A】を表示。
   - 閾値未達（< 80%）時は「80%未満」メッセージと【画像B】を表示。

## 🚀 セットアップ & 実行手順

### 1. 仮想環境の作成と有効化

```bash
# プロジェクトフォルダへ移動
cd "g:\AI\Image match"

# Python 仮想環境の作成
python -m venv .venv

# 仮想環境の有効化
# Windows (PowerShell) の場合:
.venv\Scripts\Activate.ps1
# Windows (コマンドプロンプト cmd) の場合:
.venv\Scripts\activate.bat
# macOS / Linux の場合:
source .venv/bin/activate
```

### 2. ライブラリのインストール

```bash
# 依存ライブラリのインストール
pip install -r requirements.txt

# ※ PyTorchをCPU専用で軽量にインストールしたい場合 (推奨):
# pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
# pip install streamlit transformers pillow requests
```

### 3. テスト用アセット画像の生成（初回のみ）

```bash
python generate_assets.py
```
> `assets/` ディレクトリ配下に `image_a.png`（80%以上用）、`image_b.png`（80%未満用）、サンプル画像（`sample_cat.png`, `sample_dog.png`）が生成されます。

### 4. アプリケーションの起動

```bash
streamlit run app.py
```

ブラウザが自動的に開き、`http://localhost:8501` でアプリが利用可能になります。

## 💡 使い方

1. **概念テキストの設定:**
   - 画面左側のサイドバーで「比較テキスト (Prompt)」を確認・変更します（例: `a photo of a cat`）。
2. **閾値の調整:**
   - 「合格閾値」スライダーで条件分岐の境界値（初期値: 80%）を調整できます。
3. **画像のアップロード:**
   - メイン画面のファイルアップローダーに判定したい画像をドラッグ＆ドロップします。
   - すぐに試したい場合は「🐱 猫のサンプル」または「🐶 犬のサンプル」ボタンをクリックしてください。
4. **結果の確認:**
   - 算出された類似度スコア（%）と、判定結果メッセージ、および対応する画像（【画像A】または【画像B】）が表示されます。

## ⚙️ 類似度スケーリングの仕組み

CLIPモデルの画像-テキスト間のコサイン類似度は通常 `0.15` 〜 `0.35` 程度に収まります。
そのため本アプリでは、以下のマッピング方式を選択可能にしています：

- **Min-Max 線形スケーリング（デフォルト・推奨）:**
  - 類似度 `0.16`（関連性が低い画像）を `0%`
  - 類似度 `0.32`（強く一致する画像）を `100%`
  - として自然なパーセンテージに変換します。基準値はサイドバーの「🛠️ CLIP類似度スケーリング調整」から微調整できます。
- **シグモイド補正:**
  - 中心値（Midpoint: 0.24）を50%とし、滑らかなS字カーブでパーセンテージに変換します。
- **生コサイン類似度:**
  - `コサイン類似度 × 100%`（未補正）の値をそのまま表示します。
